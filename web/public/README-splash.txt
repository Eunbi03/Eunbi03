인트로/퇴근 안내 이미지 안내
============================
아래 3개 파일을 이 폴더(web/public/)에 정확한 파일명으로 넣어주세요.

  1) intro1.png   — 앱 실행 첫 화면 (TimeCard 로고). 2초 노출
  2) intro2.png   — 두 번째 인트로 (지구와 인간의 건강한 가치실현). 2초 노출
  3) checkout.png — 퇴근 완료 후 안내 (오늘 하루도 수고하셨습니다!). 3초 노출

- 세로형 PNG 권장. 화면에 비율 유지(contain)로 표시됩니다.
- 어느 화면이든 터치하면 시간이 지나지 않아도 즉시 다음으로 넘어갑니다.
- 파일이 없으면 그라데이션 배경 + 텍스트로 임시 표시됩니다.
- 교체 후에는 web 컨테이너를 다시 빌드해야 반영됩니다.
