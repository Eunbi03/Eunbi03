관리자 · 개발자 설명서

관리자 콘솔 사용법과 개발·운영 가이드 (내부용)

🔐 로그인 · 기기 관리

  • 관리자는 등록된 기기만 접속 가능. 미등록 기기는 승인요청(관리자명·전화·권한·권한팀) → 권한자 승인.
  • 이미 쓰는 관리자명으로는 스스로 등록 불가 → 권한자가 기기 등록 초대 링크 발송.
  • 기기별 잠금 중요 — 한 기기가 비번을 여러 번 틀려 잠겨도, 다른 관리자/기기는 영향 없음. 잠긴 기기는 권한자가 기기 목록에서 잠금해제.

🧩 권한 체계 중복 선택

권한은 중복 선택 가능. 같은 관리자명으로 등록된 기기들은 권한을 공유합니다.

권한할 수 있는 일
읽기 전용조회만. 추가·수정·삭제·발송 버튼이 보이지 않음.
근로자관리 쓰기근로자 추가·수정·삭제·비번초기화·기기변경·엑셀 + 자율 메시지 발송.
개별리포트(연차)리포트 발송 + 연차 인정.
개별리포트(전체)발송 + 연차·출퇴근·근무노트 인정.
설정 쓰기설정 탭 추가·수정·삭제.
권한자위 전부 + 기기 관리 + 로그 탭. 체크 무관 모든 권한.
일반 관리자는 자신의 권한 팀 근로자만 보이고 다룰 수 있습니다.

👥 근로자 관리

  • 추가·수정·삭제·비번초기화(전화번호로)·기기변경(다음 로그인 기기 자동 등록)·잠금해제.
  • 엑셀 일괄 등록 — 시트명 직원 관리, 2행 헤더·3행부터. 열: 이름·직책·전화·이메일·근무지·비고·법인·본부·팀·직무·근무노트제외·비정기적.
  • 검증 중요 — 법인/본부/팀/직무가 설정에 등록된 값이 아니면 그 행은 실패. 결과 팝업에 누가·왜 실패했는지 표시(예: 팀 'XX' 미등록).
  • 중복 판정은 전화번호 기준(활성 전화번호면 실패, 삭제됐던 번호면 복구).

✉️ 자율 메시지 발송 근로자관리 쓰기

근로자 관리 탭 → 우측 ✉️ 메시지 발송. 앱 설치 안내 등 상황별 발송.

  • 발송 방식: 둘 다(이메일 있으면 이메일, 없으면 문자) / 문자 / 이메일.
  • 대상: 법인·본부·팀·직위 필터 또는 이름 검색(여러 명). 문제계정만(기기미등록·비번미변경·잠김)으로 미설치자만 선별 가능.
  • 발송 전 확인 팝업, 문제계정만이면 추가 확인 팝업.
  • 파일 첨부(PDF·PNG·JPG) — 이메일은 첨부+링크, 문자는 다운로드 링크. (30일 후 자동 삭제)
  • 내용은 설정 → 발송 메시지 관리 → 자율 메시지에서 작성. 치환자: {name}{corp}{team}…{manual}{managers} 등. ({managers} = 법인 담당자 문의처)
문자는 본문의 https:// 링크가 자동 클릭됨. 이메일도 URL 자동 링크화. 설치 링크는 본문에 그대로 붙여넣으면 됩니다.

⚙️ 설정 · 수정 전파 설정 쓰기

법인 / 본부·팀 / 직책 / 근무시간 및 직무 / 근무지 / 공휴일 / 발송 메시지.

수정 전파 규칙 — 설정에서 이름을 바꾸면 그 값을 쓰는 근로자도 자동 변경됩니다.
  • 법인명 변경 → 그 법인 근로자 + 관리자 담당법인
  • 본부명/팀명/직책명 변경 → 그 값 근로자 (+팀명은 관리자 권한팀도)
  • 직무 근무/휴게시간 변경 → 기존 시간 그대로였던 근로자만 (개별 조정자는 제외) / 직무명 변경은 전원

📍 근무지 — 거래처 > 지점

  • 지점 여러 개면 거래처로 묶여 표시(거래처명 + 참고반경, 아래 N개 점). 거래처 클릭 → 지점 펼침.
  • 참고반경은 거래처 공통. 거래처 '수정'에서 거래처명·반경을 바꾸면 모든 지점에 적용.
  • 거래처 행 '추가' → 지점 추가 / 지점명 클릭 → 지점명·주소 수정 / 지점 '삭제' → 체크 후 확인으로 다중 삭제.
  • 같은 거래처명으로 추가 시 "지점으로 추가하시겠습니까?" 팝업. 지점 1개면 평면 형태 유지.
  • 삭제는 비활성 처리 → 과거 출퇴근 기록 보존(목록에서만 사라짐).
  • 엑셀: 시트명 근무지 추가 — A 거래처명 / B 지점명(빈칸 가능) / C 참고반경 / D 주소 / E 상세주소.

📝 로그 (작업 기록) 권한자 전용

  • 근로자·관리자·설정·근무지·리포트·메시지·인정·기기 등 모든 변경을 일시·관리자·작업·구분·대상·비고로 기록.
  • 비고에 전후값: (법인명)케이프라이드->(주)케이프라이드, (출퇴근)09:00~18:00->08:00~17:00 등.
  • 엑셀 일괄 등록은 성공자 명단 + 실패자(사유)까지 기록.
  • 기간·관리자명·근로자명 검색. 1년 보관 후 자동 삭제.

🛡️ 권한자 3명 유지 규칙

  • 권한자(= 같은 관리자명 그룹)는 항상 최소 3명(3그룹) 유지.
  • 마지막 권한자 그룹의 기기 삭제·권한자 이전·이름 변경(병합)은 3명 미만이 되면 차단.
  • 권한자를 넘기려면 '권한자 변경' 버튼 사용. (이름 변경으로 권한을 옮기지 않음)

🚀 배포

# NAS 리포 디렉터리에서
git pull origin <branch>
sudo docker compose build api web   # 둘 다 빌드
sudo docker compose up -d
용어·UI가 안 바뀌면 대개 web 미빌드 또는 브랜치 미반영. api 기동 시 migrations/*.sql 자동 실행.

🧩 권한 · 잠금 모델

  • 권한은 기기(admin_devices) + 같은 device_name 그룹 공유. permissions TEXT[](staff/report_leave/report_full/settings), is_authority.
  • 로그인 잠금은 관리자=기기별(admin_devices.is_locked), 근로자=계정별(users.is_locked).
  • 권한자 그룹 최소 3 유지 — 삭제/이전/병합에서 가드. 상수 MIN_AUTHORITY_GROUPS.
  • 유효 키·정규화 api/src/utils/permissions.ts.

🗄️ 데이터 & 잡

주요 테이블

  • users 근로자/관리자(공용)
  • admin_devices 관리자 기기·권한·잠금
  • workplaces(client_name/branch_name/is_active)
  • attendance_records, audit_logs(1년)
  • message_templates, message_attachments(30일)

스케줄러

  • 랜덤 위치확인 슬롯 생성
  • 감사 로그 1년 경과 삭제(04:10)
  • 첨부파일 30일 경과 삭제(04:15)

✉️ 알림 · 첨부

  • 이메일 SMTP: SMTP_HOST/USER/PASSWORD, 포트 465면 secure. 문자: SOLAPI(SOLAPI_API_KEY/SECRET, SMS_SENDER).
  • 발송 문구는 message_templates DB 행(코드 기본값은 최초 시드용). URL은 본문에서 자동 링크화.
  • 첨부는 DB(bytea) 저장, 공개 다운로드 /api/files/:id. 업로드 /admin/message-attachment(multer, 20MB).

⚠️ 주의

  • 엑셀 업로드 시트명 직원 관리는 데이터 매칭용 — 변경 금지(콘솔 용어는 '근로자').
  • 다운로드/리포트 링크는 PUBLIC_BASE_URL이 외부 접근 주소여야 열림.
  • 근무지/조직 삭제는 soft delete — 과거 기록 보존.
