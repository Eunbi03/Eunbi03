## 1. 시스템 한눈에 보기

직원의 **출퇴근**을 기록하고, 근무 중 **무작위 시간에 위치를 확인**하여 실제 근무 여부를 점검하는 시스템입니다.

- **근로자**는 휴대폰 앱으로 출근/퇴근을 누르고, 외근·업무노트를 기록합니다.
- **관리자**는 전체 출퇴근 현황, 개인별 리포트, 직원 관리, 설정을 합니다.
- **랜덤 위치 확인**은 하루 3번 무작위 시각에 직원의 위치를 자동으로 수집합니다.

화면은 두 종류입니다.

| 화면 | 접속 경로 | 사용자 |
|------|-----------|--------|
| 근로자용 | 기본 주소 (`회사주소/`) | 근로자 |
| 관리자용 | 기본 주소 + `/admin.html` | 관리자(HR/Admin) |

## 2. 앱 설치와 접속

이 시스템은 **① 휴대폰 앱(안드로이드 APK)**, **② 홈 화면 설치형 웹앱(PWA)**, **③ 브라우저 접속** 세 가지 방식으로 쓸 수 있습니다.

### 근로자 (안드로이드 앱 권장)
- 백그라운드 위치 수집·알림이 필요하므로 **안드로이드 앱(APK)** 설치를 권장합니다.
- 앱 설치 후 **위치 권한을 "항상 허용"**, **배터리를 "제한 없음"** 으로 설정해야 앱을 닫아도 랜덤 위치확인이 동작합니다.
- 아이폰/PC는 브라우저(`회사주소/`)로도 쓸 수 있으나, **앱을 켜둔 상태에서만** 위치가 수집됩니다.

### 관리자
- 크롬으로 **`회사주소/admin.html`** 에 접속합니다. (또는 관리자용 PWA를 홈 화면에 설치)
- 관리자 화면에는 인트로/퇴근 안내 화면이 나오지 않습니다.

> 💡 근로자용·관리자용은 서로 다른 앱(주소)입니다. 관리자는 반드시 `admin.html`로 접속하세요.

## 3. 역할(권한) 정리

역할은 **3가지**이며 할 수 있는 일이 다릅니다. **HR은 Admin이 하는 모든 일 + 민감한 작업**까지 할 수 있습니다.

| 역할 | 설명 |
|------|------|
| **HR(인사)** | 최고 관리자 |
| **Admin(관리자)** | 일반 관리자 |
| **Worker(근로자)** | 일반 직원 |

### 기능별 권한표

| 기능 | Admin | HR |
|------|:---:|:---:|
| 전체 현황·개별 리포트 **조회** | ✅ | ✅ |
| 직원 추가/수정/삭제 | ✅ | ✅ |
| 직원 **비밀번호 초기화·기기 초기화·잠금 해제** | ✅ | ✅ |
| 직원 **기기변경 요청 승인/반려** | ✅ | ✅ |
| **설정 관리**(근무지·공휴일·법인·본부·팀·직책·근무시간) | ✅ | ✅ |
| **연차 인정**(하루 전체 인정) | ✅ | ✅ |
| 관리자 계정 **이름** 수정 | ✅ | ✅ |
| **출근/퇴근/노트 인정** 처리 | ❌ | ✅ |
| **리포트 발송**(이메일·문자) | ❌ | ✅ |
| 관리자 계정 **비밀번호** 변경 | ❌ | ✅ |
| **관리자 기기** 승인·삭제·권한자 변경·기기정보 수정 | ❌ | ✅ |

> 일반 Admin에게는 위 "HR만" 기능의 버튼이 보이지 않거나 비활성화됩니다.

## 4. 로그인과 첫 설정

### 근로자의 첫 로그인 3단계
1. **로그인** — **전화번호**(숫자만) + 초기 비밀번호
   - 초기 비밀번호는 **전화번호의 숫자만** (예: `010-1234-5678` → `01012345678`)
2. **비밀번호 변경** — 첫 로그인 시 반드시 새 비밀번호로 변경 (영문·숫자 포함 8자 이상)
3. **위치 정보 동의** — 출퇴근·위치 확인을 위해 동의해야 합니다.

### 관리자 로그인
- 관리자는 **이메일 + 비밀번호**로 `admin.html`에서 로그인합니다.

### 기기 등록(중요)
- 근로자 계정은 **처음 로그인한 기기 1대에만** 묶입니다(기기 바인딩).
  - 여기서 "기기"는 **휴대폰 앱뿐 아니라 PC 브라우저도 포함**합니다. 먼저 로그인한 쪽이 등록되고, **폰과 PC를 동시에 쓸 수는 없습니다.** (한쪽만 사용 가능)
  - 같은 PC라도 브라우저를 바꾸거나 캐시(브라우저 데이터)를 지우면 다른 기기로 인식될 수 있습니다.
- 다른 기기에서 로그인하면 막힙니다. 기기를 바꾸면 관리자가 **기기 초기화**를 해줘야 합니다.
  - (비밀번호가 맞아도 등록되지 않은 기기면 로그인은 거부되지만, **계정이 잠기지는 않습니다.**)

### 로그인 실패 잠금
- **비밀번호**를 5회 틀리면 계정이 **자동 잠깁니다.** (기기 불일치는 잠금 대상 아님)
- 잠긴 계정은 관리자가 직원 관리에서 **잠금 해제**하면 풀립니다.

## 5. 근로자(직원) 앱 사용법

### 앱 실행
- 앱을 열면 인트로 화면이 잠깐 표시된 뒤 로그인/메인 화면으로 넘어갑니다.

### 출근
- 메인 화면에서 **[출근하기]** 를 누릅니다. (위치를 가져올 수 없으면 출근되지 않습니다)
- 근무 시작 시간보다 늦으면 자동으로 **지각**으로 기록됩니다.
- 출근은 **하루 1번**만 가능합니다.

### 외근(이동)·복귀
- 근무 중 외부로 나갈 때 **[외근]** 을 눌러 목적지·사유를 적습니다.
  - 목적지는 등록된 근무지를 선택하거나 직접 입력할 수 있습니다. (등록 근무지 선택 시 거리 계산)
- 외근을 시작하면 버튼이 **[외근] [복귀] [퇴근하기]** 3개로 바뀝니다.
- **[복귀]** 를 누르면 외근이 종료되고 기본 근무지로 돌아온 것으로 처리됩니다. (다시 [외근] [퇴근하기] 2개로)
- 장소를 옮겨다니며 외근을 이어서 할 수 있습니다.

### 퇴근
- **[퇴근하기]** 를 누르고 필요하면 업무노트를 함께 작성합니다.
- 퇴근 업무노트 자동 기입:
  - **외근지**는 오늘 다녀온 외근지가 자동으로 채워집니다.
  - **외근지에서 바로 퇴근**하면(복귀하지 않은 경우) "외근지에서 바로 퇴근하시겠습니까?" 팝업이 뜨고, "예"면 퇴근지에 외근지가 채워집니다.
  - **복귀 후 퇴근**하면 팝업 없이 퇴근지에 **기본 근무지**가 채워집니다.
  - **외근지로 출근한 경우**(기본 근무지 반경 밖에서 출근을 누르고, 30분 이내에 외근을 기록) → 퇴근 시 **"출근 장소"** 가 그 외근 목적지로 자동 기입됩니다.
- 퇴근하면 "오늘 하루도 수고하셨습니다" 안내 화면이 잠깐 표시됩니다.

### 근무노트
- 출근 후 언제든 **[근무노트 작성]** 으로 오늘 업무를 기록할 수 있습니다.
- 노트를 쓰지 않으면 "노트 누락"으로 집계됩니다. (근무노트 제외 대상 직원은 예외)

## 6. 알림 기능

근로자 **앱(안드로이드)** 에 다음 알림이 자동으로 갑니다.

| 알림 | 언제 |
|------|------|
| **출근 체크 잊지 마세요!** | 출근 예정시간 **5분 전** (근무일에만, 아직 출근 안 했을 때) |
| **퇴근 체크 잊지 마세요!** | 퇴근 예정시간 **5분 전** (출근을 눌렀고 아직 퇴근 안 했을 때) |
| **근무노트가 아직 작성되지 않았어요!** | 퇴근 예정시간 (출근을 눌렀고 노트가 없을 때) |

### 알림 규칙
- **정기 근무자**: **주말·공휴일에는 출근 알림이 가지 않습니다.** (근무일만)
- 출근/퇴근 버튼을 이미 눌렀다면 해당 알림은 가지 않습니다.
- **비정기 근무자**: **알림이 전혀 가지 않습니다.**
- 알림은 안드로이드 앱에 알림 권한이 허용된 경우에 동작합니다.

## 7. 랜덤 위치 확인 — 가장 중요한 기능

근무 중 **무작위 시각에 직원의 위치를 자동으로 수집**해, 실제 근무 여부를 점검합니다.

### 7-1. 언제, 몇 번 만들어지나
- **하루 3회**, 직원마다 무작위 시각으로 생성됩니다.
- 생성 시점:
  - **매일 새벽 5시(자동)** — 그날 활성 **정기 근무자**에 대해 미리 생성
  - **직원을 새로 등록/재활성화할 때** — 그날 남은 시간에 대해 즉시 생성
- 직원마다 시각이 **매일 다릅니다.**
- **주말·공휴일에는 생성되지 않습니다.** 또한 **비정기 근무자**는 랜덤 확인 대상이 아닙니다.

### 7-2. 시각을 정하는 규칙
- 하루를 **오전(출근~점심)** / **오후(점심~퇴근)** 로 나눕니다. **점심시간은 제외**합니다.
- 3회를 **2:1로 나눠** 배분합니다. (오전 2·오후 1 또는 오전 1·오후 2 — 매번 무작위)
- 같은 구간의 두 번은 **최소 1시간 30분(90분) 간격**을 둡니다.
- **출근 시각 이후 1시간, 퇴근 시각 이전 1시간**은 확인 대상에서 제외합니다.
  - 예) 9시 출근·18시 퇴근·점심 12~13시 → **오전 10:00~12:00**, **오후 13:00~17:00** 사이에서 생성.

### 7-3. 어떻게 수집되나 (직원 입장)
- **안드로이드 앱 + 위치 "항상 허용" + 배터리 "제한 없음"** 이면, 앱을 닫아둬도 해당 시각에 **자동으로** 위치가 전송됩니다. (백그라운드 무음 푸시)
- 브라우저/아이폰 등에서는 **앱을 켜둔 상태**에서만 수집됩니다.
- **마감은 해당 시각 + 5분**입니다. 5분 안에 수집되지 않으면 **미응답**으로 확정됩니다.

> ⚠️ 위치를 꺼두거나(권한 거부), 앱을 강제 종료(설정 → 강제 중지)해두면 수집되지 않고 **미응답**으로 기록됩니다.
> 최근앱에서 밀어 닫아도 배터리 "제한 없음"이면 대부분 수집되지만, 일부 기기는 예외일 수 있습니다.
> 출근이 늦어져 랜덤 시각과 가까워도 정상적으로 수집합니다(제외하지 않습니다).

### 7-5. 앱을 켠 상태의 GPS 감지
- 출근을 누르면 앱이 GPS 감지를 시작하고, **퇴근을 누르면 종료**합니다.
- 퇴근을 누르지 않아도 **기본 퇴근시간 + 2시간**이 되면 GPS 감지가 자동 종료됩니다.
- 로그아웃하거나 다른 화면으로 이동해도 근무 세션 동안은 유지됩니다. (배터리 절약을 위한 자동 종료는 그대로 동작)

### 7-6. 플랫폼별 위치 수집 차이 (안드로이드 / 아이폰)

위치 수집 방식은 **안드로이드와 아이폰이 다릅니다.**

| 상황 | 안드로이드 | 아이폰(iOS) |
|------|-----------|-------------|
| 앱을 켠 상태 | ✅ 수집 | ✅ 수집 |
| 앱을 닫아둔 백그라운드 | ✅ 무음 푸시로 정해진 시각에 자동 수집 | ⚠️ OS 제약으로 "정해진 시각에 앱 깨우기"가 불가 |

- **안드로이드**: 앱을 닫아둬도, 서버가 랜덤 시각에 보낸 **무음 푸시**로 자동 수집됩니다. (현재 동작 중)
- **아이폰**: iOS는 서버가 정한 시각에 백그라운드 앱을 깨울 수 없습니다. 그래서 **근무 시간 동안 위치 추적을 켜 두고(저정밀), 하루 5시각에만 전송**하는 방식으로 설계되어 있습니다.
  - **"항상 허용"** 위치 권한이 필요하고, **근무 시간 외에는 수집하지 않습니다.**
  - iOS 특성상 화면 상단에 위치 사용 표시가 뜨고, 사용자가 권한을 "앱 사용 중에만"으로 낮추면 백그라운드 수집이 멈춥니다.
  - **구현 상태**: 아이폰 백그라운드 수집 코드는 구현되어 있으며, 맥(Xcode)에서 iOS 앱을 빌드·배포해야 동작합니다. 실기기 최종 검증 후 사용하세요.

> 요약: 백그라운드 자동 수집은 **안드로이드는 완전히 동작**, **아이폰은 구현되어 있으나 실기기 검증 단계**입니다. 검증 전에는 아이폰은 앱을 켠 상태에서 수집됩니다.

### 7-4. 리포트에 보이는 상태
개별 리포트의 각 랜덤확인은 다음 중 하나로 표시됩니다.

| 표시 | 의미 |
|------|------|
| ✅ 체크 | 수집된 위치가 근무지 반경 안 |
| ❗ 느낌표 | 근무지 반경 밖이거나, 5분 내 미수집(미응답) |
| ⏳ 모래시계 | 아직 그 시각이 오지 않음(예정) |

- **근무지**(위치·반경) 등록/수정/삭제 — 기본 반경 **500m**(사업장별로 수정 가능)
- **공휴일** 등록/삭제
- **법인 · 본부 · 팀 · 직책 · 근무시간** 관리
- 엑셀 업로드 지원

> 관리자 계정의 **기기 승인/삭제/권한자 변경/기기정보 수정**은 HR만 할 수 있습니다.

## 9. 근태 평가 기준(KPI)과 관리대상

### 4가지 집계 항목
| 항목 | 언제 발생하나 |
|------|----------------|
| **지각** | 출근 시각이 근무 시작보다 늦음 |
| **출근 누락** | 근무일인데 출근 기록 없음 |
| **퇴근 누락** | 출근은 했으나 퇴근 기록 없음 |
| **노트 누락** | 업무노트가 없음 (상황 불문, 노트 제외 대상·노트 인정 제외) |

### 점수 계산식
```
점수 = (출근누락 · 퇴근누락 · 지각 중 하루 1건) + 노트누락
```
- **하루에 출근누락·퇴근누락·지각은 최대 1건**만 셉니다. (우선순위: 출근누락 > 퇴근누락 > 지각)
  - 예) 지각하면서 퇴근도 누락한 날 → **1건(퇴근누락)** 으로 계산
- **노트 누락은 별도**로 셉니다.
- **점수가 5점 이상이면 "관리대상"** 으로 표시되며, 리포트에 시말서 안내가 표시됩니다.

> 이 기준은 전체현황 대시보드, 개별 리포트, 발송 리포트 모두 **동일**하게 적용됩니다.

### 주말·공휴일 규칙 (개별 리포트 표시)
- **주말·공휴일은 근무일에서 제외**됩니다(출근 안 해도 누락 아님).
- 개별 리포트에는 주말·공휴일도 모두 표시되며, 근무일이 아니면 **회색 "비근무일" 라벨**로만 표기됩니다(누락 문구 없음).
- 단, 다음 중 하나라도 있으면 그날은 **근무일로 취급**되어 평가에 반영됩니다.
  - 직원이 **실제로 출근 버튼을 눌렀거나**
  - 관리자가 **인정(출근/퇴근/노트/연차 등 무엇이든)** 을 한 경우

### 인정 처리 (부분 인정 주의)
- **연차**: 그날은 평가에서 완전히 제외 (모든 관리자)
- **출근/퇴근/출퇴근 인정**: 실제 기록이 없어도 인정 (HR만)
- **노트 인정**: 업무노트 누락 면제 (HR만)
- ⚠️ **부분 인정**: 비근무일에 예컨대 **출근만 인정**하면 그날이 근무일이 되어 **퇴근 누락·노트 누락**이 발생할 수 있습니다. 필요하면 출퇴근·노트 인정을 함께 눌러야 누락이 잡히지 않습니다.
- **인정 취소**: 인정을 다시 눌러 해제하면 그날은 다시 **비근무일**로 돌아가 누락 집계에서 빠집니다.

### 리포트 달력의 공휴일
- 개별 리포트 달력에서 공휴일은 날짜 옆에 **공휴일 이름**(설정 → 공휴일 관리에 등록한 이름)이 붉은색으로 표시됩니다.

## 10. 직원 등록·수정·삭제

### 등록
- 직원 관리 → 직원 추가. **이름은 필수, 이메일은 선택**입니다.
- 등록하면 **초기 비밀번호**(전화번호 숫자)가 발급되고, 그날 남은 랜덤확인 슬롯도 자동 생성됩니다.
- **비정기 근무자**로 지정하면 알림이 가지 않습니다.
- **근무노트 제외 대상**으로 지정하면 노트 누락으로 집계되지 않습니다.

### 수정
- 이름·연락처·소속(법인/본부/팀/직책)·근무시간·근무지 등을 변경할 수 있습니다.
- ⚠️ 근무시간을 바꿔도 **이미 생성된 그날의 랜덤확인 시각은 바뀌지 않습니다.** (다음 날부터 반영)

### 삭제·재등록 (전화번호 기준 · 1년 보존)
- 직원을 삭제하면 목록에서는 사라지지만, **기록은 1년간 보존**됩니다(완전 삭제가 아닌 비활성 처리).
- 삭제 후 **1년 이내에 같은 전화번호**로 다시 등록하려 하면 팝업이 뜹니다:
  > "{전화번호}에 대한 등록 이력이 존재합니다. 이전 정보를 복구하시겠습니까?"
  - **예** → 보존된 기록을 불러와 **복구**(재활성화)합니다.
  - **아니오** → 이전 기록을 **영구 삭제**하고 새 직원으로 등록합니다.
- **이메일로는 어떤 중복 검사도 하지 않습니다.** (중복 판단은 전화번호 기준)

> 같은 전화번호가 **현재 활성 상태**이면 "이미 등록된 정보입니다"로 등록이 거부됩니다.

## 11. 리포트 발송(이메일·문자)

**HR만** 사용할 수 있습니다. 개별 리포트 화면에서 **[리포트 발송]** 을 누르면 현재 보이는 인원에게 발송됩니다.

- **이메일이 있으면 → 이메일**, **전화번호만 있으면 → 문자(LMS)** 로 발송됩니다.
- 문자와 이메일 내용은 동일합니다.
- 리포트 링크를 열면 그 달의 **달력형 근태 리포트**가 표시됩니다.
- 관리대상(5점 이상)이면 **시말서 제출 안내**(발송일 + 7일)가 함께 표기됩니다.
- 법인별 담당자(등록 기기의 담당자명·전화)가 리포트에 안내됩니다.

### 기기 식별·로그인 안정성
- 기기 식별자는 **최초 1회 계산 후 고정 저장**됩니다. 폰의 시스템 WebView/크롬이 자동 업데이트돼도 로그인이 갑자기 막히지 않습니다.
  - (이 개선 배포 전에 이미 어긋난 기기는 한 번 **기기 초기화**가 필요할 수 있습니다.)
- 근로자 로그인 실패 시 **실제 사유**(예: "등록되지 않은 기기입니다. 인사팀에 기기 변경을 요청하세요.")가 화면에 표시됩니다.
- **관리자 다기기 자동로그인**: refresh 토큰을 **기기별로 저장**하므로, 다른 기기에서 로그인해도 기존 기기의 자동로그인이 유지됩니다.
- 세션 중 토큰이 만료되어도 **자동으로 재발급**되어 작업이 끊기지 않습니다.

## 13. 자주 묻는 질문(FAQ)

**Q. 새로 등록한 직원인데 랜덤확인이 안 떠요.**
A. 등록 당일에는 **남은 시간**에 대해서만 생성됩니다. 늦게 등록하면 적거나 없을 수 있고, 다음 날 새벽 5시부터 정상적으로 3개가 생성됩니다.

**Q. 직원이 앱을 닫아두면 랜덤확인을 못 받나요?**
A. **안드로이드 앱 + 위치 "항상 허용" + 배터리 "제한 없음"** 이면 앱을 닫아도 받습니다. 브라우저/아이폰은 앱을 켜둔 상태에서만 수집됩니다.

**Q. 위치가 안 잡혀서 출근/외근이 안 됩니다.**
A. 위치를 가져오지 못하면 출근·외근이 진행되지 않습니다. 위치 권한과 GPS를 확인하세요.

**Q. 폰을 바꿨더니 로그인이 안 돼요.**
A. 기기 바인딩 때문입니다. 관리자가 직원 관리에서 **기기 초기화**를 해주면 새 폰으로 로그인할 수 있습니다.

**Q. 화면이 예전 그대로예요. 새로고침해야 하나요?**
A. 새 버전이 배포되면 **앱이 스스로 감지해 자동으로 최신 화면으로 갱신**됩니다(작성 중일 때는 방해하지 않고, 앱을 나갔다 들어올 때 적용). 보통 수동 캐시 삭제가 필요 없습니다.

**Q. 일반 관리자(Admin)인데 안 보이거나 눌러도 안 되는 기능이 있어요.**
A. 출근/퇴근/노트 인정, 리포트 발송, 관리자 기기·비밀번호 관리는 **HR 전용**입니다. 설정·직원 관리·연차 인정은 일반 관리자도 가능합니다.

**Q. 삭제한 직원을 되살리고 싶어요.**
A. 삭제 후 **1년 이내에 같은 전화번호로 등록**하면 복구 팝업이 뜹니다. "예"를 누르면 과거 기록이 복구됩니다. (이메일은 중복 검사에 쓰지 않습니다.)
