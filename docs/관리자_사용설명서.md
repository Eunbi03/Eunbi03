## 1. 시스템 한눈에 보기

직원의 **출퇴근**을 기록하고, 근무 중 **무작위 시간에 위치를 확인**하여 실제 근무 여부를 점검하는 시스템입니다.

- **근로자**는 휴대폰으로 출근/퇴근을 누르고, 외출·업무노트를 기록합니다.
- **관리자**는 전체 출퇴근 현황, 개인별 리포트, 직원 관리를 합니다.
- **랜덤 위치 확인**은 하루 3번 무작위 시각에 직원의 위치를 자동으로 수집합니다.

화면은 두 종류입니다.
| 화면 | 접속 경로 | 사용자 |
|------|-----------|--------|
| 직원용 | 기본 주소 (예: `회사주소/`) | 근로자 |
| 관리자용 | 기본 주소 + `/admin` | 관리자(HR/Admin) |

## 2. 접속 주소와 역할(권한)

역할은 **3가지**이며 할 수 있는 일이 다릅니다.

| 역할 | 설명 | 할 수 있는 일 |
|------|------|----------------|
| **HR(인사)** | 최고 관리자 | 모든 관리 작업 (아래 admin이 하는 일 + **민감한 작업**) |
| **Admin(관리자)** | 일반 관리자 | 현황 조회, 개별 리포트 조회, **직원 추가/수정/삭제** |
| **Worker(근로자)** | 일반 직원 | 본인 출퇴근·외출·업무노트 |

**HR만 할 수 있는 민감한 작업**
- 근무지(사업장) 등록/수정/삭제
- 직원 **비밀번호 초기화**, **기기 초기화**, **계정 잠금 해제**
- **연차/인정 처리** (개별 리포트에서 날짜별 연차 지정)
- **공휴일 등록/삭제**
- 기기 변경 요청 승인/거부

> 💡 일반 Admin 계정은 위 작업 버튼이 **아예 보이지 않습니다.** "설정" 탭도 HR에게만 표시됩니다.

## 3. 로그인과 첫 설정

### 직원의 첫 로그인 3단계
직원이 처음 로그인하면 순서대로 진행됩니다.

1. **로그인** — 이메일 + 초기 비밀번호
   - 초기 비밀번호는 **전화번호의 숫자만** (예: `010-1234-5678` → `01012345678`)
   - 전화번호가 없으면 `초기비밀번호1`
2. **비밀번호 변경** — 첫 로그인 시 반드시 새 비밀번호로 변경해야 합니다.
3. **위치 정보 동의** — 출퇴근·위치 확인을 위해 위치 사용에 동의해야 합니다.

### 기기 등록(중요)
- 직원 계정은 **처음 로그인한 휴대폰 1대에만** 묶입니다(기기 바인딩).
- 다른 폰에서 로그인하면 막힙니다. 폰을 바꾸면 관리자가 **기기 초기화**를 해줘야 합니다.

### 로그인 실패 잠금
- 비밀번호/기기를 **5회** 틀리면 계정이 **자동 잠깁니다.**
- 잠긴 계정은 HR이 직원 관리에서 **잠금 해제**해야 풀립니다.

## 4. 근로자(직원) 앱 사용법

직원이 앱에서 하는 일입니다. (관리자가 직원에게 안내할 때 참고)

### 출근
- 메인 화면에서 **[출근하기]** 버튼을 누릅니다.
- 누른 시각이 근무 시작 시간보다 늦으면 자동으로 **지각**으로 기록됩니다.
- 출근은 **하루 1번**만 가능합니다.

### 외출(이동)
- 근무 중 외부로 나갈 때 **[외출]** 을 눌러 목적지·사유를 적습니다.
- 복귀하면 외출 종료를 누릅니다.

### 퇴근
- **[퇴근하기]** 를 누르고 **오늘 업무 내용(업무노트)** 을 작성합니다.
- 업무노트는 **퇴근 시 필수**입니다. (안 쓰면 "노트 누락"으로 집계)

### 업무노트
- 출근/퇴근/외근/오늘 업무 등을 기록할 수 있습니다.
- 관리자는 개별 리포트에서 이 내용을 확인합니다.

> ℹ️ **근무시간 변경 요청 기능은 앱에서 제거되었습니다.** 변경이 필요하면 직원이 관리자에게 직접 요청하면 됩니다.

## 5. 랜덤 위치 확인 — 가장 중요한 기능

근무 중 **무작위 시각에 직원의 위치를 자동으로 수집**해, 실제 근무 여부를 점검합니다.

### 5-1. 언제, 몇 번 만들어지나
- **하루 3회**, 직원마다 무작위 시각으로 생성됩니다.
- 생성 시점:
  - **매일 새벽 5시(자동)** — 그날 활성 직원 전원에 대해 미리 생성
  - **직원을 새로 등록/재활성화할 때** — 그날 남은 시간에 대해 즉시 생성
- 직원마다 시각이 **매일 다릅니다.**

### 5-2. 시각을 정하는 규칙
- 하루를 **오전(출근~점심)** / **오후(점심~퇴근)** 로 나눕니다.
- 3회를 **2:1로 나눠** 배분합니다. (오전 2·오후 1 또는 오전 1·오후 2 — 매번 무작위)
- 같은 구간의 두 번은 **최소 2시간 간격**을 둡니다.
- 근무시간(출근/퇴근/점심)을 기준으로 하므로, 반차 등 시간이 짧으면 3개보다 적게 생성될 수 있습니다.

### 5-3. 어떻게 수집되나 (직원 입장)
- 직원이 **앱을 켜둔 상태 + 위치 권한 허용**이면, 해당 시각에 **버튼 없이 자동으로** 위치가 전송됩니다.
- **마감은 해당 시각 + 5분**입니다. 5분 안에 수집되지 않으면 **미응답**으로 확정됩니다.
- 위치가 꺼져 있거나 앱이 닫혀 있으면 수집되지 않습니다.

> ⚠️ 웹앱 특성상, 직원이 위치를 꺼버리면 시스템이 강제로 켤 수는 없습니다.
> 대신 그 경우 **미응답으로 기록**되어 근태 평가에 반영됩니다.

### 5-4. 출근 직후 2시간 규칙
- 출근한 직후 **2시간 이내**에 잡힌 랜덤 시각은 **확인하지 않고 "제외" 처리**됩니다.
- 이는 출근하자마자 위치를 묻는 것을 막기 위한 장치이며, **미응답으로 불이익을 주지 않습니다.**

### 5-5. 리포트에 보이는 상태
개별 리포트의 각 랜덤확인은 다음 중 하나로 표시됩니다.

| 표시 | 의미 |
|------|------|
| ✅ 근무지 내 | 수집된 위치가 근무지 반경 안 |
| ⚠️ 근무지 외 | 수집됐지만 근무지 반경 밖 |
| ➖ 제외(출근직후) | 출근 2시간 이내라 확인 안 함 (불이익 없음) |
| 미응답 | 5분 내 수집 실패 (위치 꺼짐/앱 닫힘 등) |
| ⏳ 예정 | 아직 그 시각이 오지 않음 |

## 6. 관리자 화면 사용법

`/admin` 으로 접속하면 상단에 탭이 있습니다.

### ① 전체 현황 (모든 관리자)
- 팀별로 직원들의 근태 점수를 한눈에 봅니다.
- **관리대상**(아래 7번 참고) 직원이 강조 표시됩니다.

### ② 직원 관리 (조회: 모두 / 변경: 일부는 HR)
- 직원 목록 조회, **추가/수정/삭제**(Admin·HR 가능)
- **비밀번호 초기화 · 기기 초기화 · 잠금 해제**(HR만)

### ③ 개별 리포트 (모든 관리자)
- 한 직원의 기간별 출퇴근·외출·랜덤확인·업무노트를 날짜별로 봅니다.
- 상단에 그 직원의 KPI 점수와 **관리대상 여부**가 표시됩니다.
- **연차/인정 처리**(HR만): 날짜별로 연차·출근인정 등을 지정할 수 있습니다.

### ④ 설정 (HR만 — 일반 Admin에게는 탭이 안 보임)
- **근무지** 등록/수정/삭제 (위치·반경 설정)
- **공휴일** 등록/삭제

## 7. 근태 평가 기준(KPI)과 관리대상

### 4가지 집계 항목
| 항목 | 언제 발생하나 |
|------|----------------|
| **지각** | 출근 시각이 근무 시작보다 늦음 |
| **출근 누락** | 근무일인데 출근 기록 없음 |
| **퇴근 누락** | 출근은 했으나 퇴근 기록 없음 |
| **노트 누락** | 퇴근은 했으나 업무노트 없음 |

### 점수 계산식
```
점수 = (지각 × 0.5) + (출근누락 × 1) + (퇴근누락 × 1) + (노트누락 × 0.5)
```
- **점수가 5점 이상이면 "관리대상"** 으로 표시됩니다.
- 예: 지각 4회(2점) + 퇴근누락 3회(3점) = 5점 → 관리대상

### 주말·공휴일 규칙
- **주말·공휴일은 기본적으로 근무일에서 제외**됩니다(출근 안 해도 누락 아님).
- 단, 직원이 주말에 **실제로 출근 버튼을 눌렀다면** 평일처럼 평가에 반영됩니다.
- 개별 리포트에는 주말이라도 **출근했거나 연차 처리된 날만** 표시됩니다.

### 연차·인정 처리(HR)
관리자가 날짜에 다음을 지정할 수 있습니다.
- **연차**: 그날은 평가에서 완전히 제외
- **출근/퇴근/출퇴근 인정**: 실제 기록이 없어도 출근/퇴근한 것으로 인정
- **노트 인정**: 업무노트 누락을 면제
- (예: `출퇴근+노트` = 출근·퇴근·노트 모두 인정)

## 8. 직원 등록·수정·삭제

### 등록
- 직원 관리 → 직원 추가. 이메일·이름은 필수.
- 등록하면 **초기 비밀번호**(전화번호 숫자)가 발급되고, 그날 남은 랜덤확인 슬롯도 자동 생성됩니다.

### 수정
- 이름·연락처·소속·근무시간·근무지 등을 변경할 수 있습니다.
- ⚠️ 근무시간을 바꿔도 **이미 생성된 그날의 랜덤확인 시각은 바뀌지 않습니다.** (다음 날부터 반영)

### 삭제 (중요 — 기록 보존 방식)
- 직원을 삭제하면 목록에서는 사라지지만, **출퇴근 기록은 보존**됩니다(완전 삭제가 아닌 비활성 처리).
- **같은 이메일로 다시 등록하면**, 예전 직원이 **자동으로 되살아납니다(재활성화).**
  - 정보가 새로 입력한 값으로 갱신되고, 비밀번호·기기가 초기화됩니다.
  - **과거 근태 기록이 그대로 이어집니다.**
- 즉, 퇴사 후 재입사 같은 상황에서 같은 사람의 이력을 이어서 관리할 수 있습니다.

> 같은 이메일이 **현재 활성 상태**이면 "이미 등록된 이메일입니다"로 등록이 거부됩니다.

## 10. 자주 묻는 질문(FAQ)

**Q. 새로 등록한 직원인데 랜덤확인이 안 떠요.**
A. 등록 당일에는 **남은 시간**에 대해서만 생성됩니다. 늦은 시각에 등록하면 적거나 없을 수 있고, 다음 날 새벽 5시부터 정상적으로 3개가 생성됩니다.

**Q. 직원이 위치 권한을 꺼두면요?**
A. 시스템이 강제로 켤 수 없습니다. 그 시각은 **미응답**으로 기록되어 점검에 반영됩니다.

**Q. 직원이 앱을 닫아두면 랜덤확인을 못 받나요?**
A. 자동 수집은 앱이 켜져 있을 때 동작합니다. 닫혀 있으면 미응답 처리됩니다. (푸시 알림 기능은 현재 사용하지 않습니다.)

**Q. 삭제한 직원을 되살리고 싶어요.**
A. **같은 이메일로 다시 등록**하면 기존 직원이 재활성화되며 과거 기록이 복구됩니다.

**Q. 출근하자마자 랜덤확인이 와서 부당하다고 합니다.**
A. 출근 후 **2시간 이내** 랜덤확인은 자동으로 "제외" 처리되어 불이익이 없습니다.

**Q. 일반 관리자(Admin)인데 설정 탭이 안 보여요.**
A. 정상입니다. 근무지·공휴일·초기화 등은 **HR 권한**에서만 가능합니다.

## 11. 용어 정리

| 용어 | 뜻 |
|------|-----|
| **HR / Admin / Worker** | 인사관리자 / 일반관리자 / 근로자 |
| **랜덤 위치 확인** | 하루 3회 무작위 시각에 위치를 자동 수집하는 점검 |
| **미응답** | 랜덤확인 시각 +5분 내 위치가 수집되지 않음 |
| **제외(출근직후)** | 출근 2시간 이내라 확인하지 않은 랜덤확인 (불이익 없음) |

| **기기 바인딩** | 계정을 휴대폰 1대에 묶는 보안 기능 |
| **재활성화** | 삭제(비활성)된 직원을 같은 이메일 재등록으로 되살리는 것 |
| **근무지(사업장)** | 위치·반경이 설정된 근무 장소. 랜덤확인의 "근무지 내/외" 판정 기준 |
